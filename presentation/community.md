# Fender Studio Pro X community

## Where to talk

Talk happens in **[GitHub Discussions](https://github.com/ferrerokush-png/fender-studio-pro-x/discussions)**, next to the code. It has six categories:

- **Announcements:** new versions and news. Only the maintainer posts here.
- **General:** anything about Fender Studio Pro X.
- **Ideas:** suggest a package, a skin or a change.
- **Polls:** help decide what comes next.
- **Q&A:** ask how something works. Mark the answer that solved it.
- **Show and tell:** share your skins, themes, songs and setups.

**Bugs do not go in Discussions.** They go to **[GitHub Issues](https://github.com/ferrerokush-png/fender-studio-pro-x/issues)**, using the bug-report form.

**Themes come ready-made in 2.0.0.** The text-file theme kit of 1.4.1 has not been remade for the new themes, so there is nothing to build yet. Show your look (theme, accent, options) in Show and tell with a screenshot.

**Later, if people ask for it:** a Discord server and a themes gallery page. Not before there are real users.

## Reporting a bug

Open a new Issue and pick the **bug-report form**. Have these ready: your Studio Pro version (Help > About, or the version in the installer), the pack version (2.0.0), which packages and switches you have on, what you did, what you expected, and the log `%LOCALAPPDATA%\StudioMods\studio-pro-x\sandbox.log`. First check whether holding Shift at start makes the problem go away.

## House rules

- **Respect the program and the people who make it.** This is a thank-you to the Studio One team, not a replacement.
- **Never touch licensing.** No changes to sign-in, accounts, activation, subscriptions or the store, and no help with that. Posts about it are removed.
- **No Fender files.** No skin files, images, fonts, program files or extracted code in contributions. Themes are settings only.
- **Your own work only.** Packages ship your own code and assets. Say the licence (MIT preferred) and the licence of any model or tool you use.
- **Say what you tested on.** Studio Pro build and Windows version.
- **Be kind.** Many people here are musicians first and coders second.

## Pull requests

Small and focused, one change each, tested on Studio Pro 8.2, our code only. Every addition lives in one of the 12 packages (or is a new package), with a README line, an off switch and a clean uninstall. A package that needs Skins says so.
