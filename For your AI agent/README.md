# For your AI agent

`STUDIO-PRO-INTERNALS-FOR-AI-AGENTS.md` is a briefing written for an AI coding agent (Claude Code or similar). It explains how
Fender Studio Pro 8 works inside (skins, windows, web panels, commands, song scripting, the mod loader in this pack) so your
agent can start building your own mods right away instead of spending weeks mapping the program first.

How to use it: put the file in your mod project folder and tell your agent "read STUDIO-PRO-INTERNALS-FOR-AI-AGENTS.md first",
or copy its contents into your project's `CLAUDE.md` (or your agent's equivalent instructions file). Work in a copy of
Studio Pro, never your real install, and keep the pack's "hold Shift at start" and Uninstall routes back to stock.

These mods and notes are vibe-coded by a non-programmer. Facts were checked on one build on one machine; some may be wrong.
Verify before you rely on them.

Checked on Studio Pro 8.1.2 (build 8.1.2.113407), Windows 11. Unofficial fan project; not made or supported by Fender or PreSonus.
